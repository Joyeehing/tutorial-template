Requirement 3: Users should be able to create listings easily
===========================================================
User should be able to create listings
--------------------------------
.. image:: ../images/req3/sec1/image1.png
    :width: 600px
    :align: center
    :alt: Image of the project page

The user logs in to their account and selects the “Create Listing” option from the marketplace page or account section. The system then opens the listing creation form, where the user can upload an image and enter item details such as the product name, category, size, condition, price, colour, material, and description before submitting the listing. Once the input has been validated successfully, the listing is saved to the system, displayed in the marketplace, and can later be managed through the user’s account section.

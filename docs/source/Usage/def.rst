Definitions
===========

Thryft is a mobile application designed to enable users to buy and sell second-hand clothing easily. The app promotes sustainable fashion by encouraging users to reuse and recycle clothing items instead of purchasing new ones.
The target audience includes students, young adults, and individuals who are interested in affordable fashion and environmentally friendly shopping habits.

The system is designed to support structured interactions between buyers and sellers through clearly defined features such as item filtering, seller trust information, wishlist management, and an offer-based pricing mechanism.
To ensure usability and efficiency, the platform incorporates validation rules and constraints, such as restricting invalid offer values and maintaining clear listing attributes. These constraints help maintain data integrity and provide a consistent user experience.

Additionally, the system supports user-specific functionalities, including tracking orders, managing listings, and receiving notifications for relevant updates. This ensures that users can effectively monitor their activities within the platform.
Overall, the system focuses on balancing flexibility and control, allowing users to interact freely while ensuring that all actions remain within defined system rules.

Thryft provides the following key features:
---------------------------------------------
1. Users should be able to Filter Items
2. Users Should be able to View Seller Trust Information
3. Users should be able to create listings easily
4. Users should be able to edit and manage their listings
5. Users Should Be Able to View Their Purchase and Listing History
6. Buyers Should Be Able to Track Their Orders
7. Buyers should be able to offer a new price for a listing
8. Users should be able to save listings (wishlist)
9. Users Should Receive Notifications
10. Users Should Be Able to Register and Log in Securely

The application is built using Flutter and Dart, with backend support for authentication and data storage to ensure secure and efficient operations.
